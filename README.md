# N-Panel Manager: Toolbar Organizer

This Blender add-on manages the **left-hand 3D View Toolbar** shown in the
reference screenshot (the region toggled with `T`). Despite the project name,
that region is Blender's Toolbar; the N-panel is the sidebar on the right.

## Features

- A permanent gear button at the top of the 3D View Toolbar.
- The manager dialog uses Blender's real tool icons.
- Checkboxes show or hide toolbar buttons immediately.
- Move buttons place tools at the top, up one row, down one row, or at the
  bottom.
- Blender flyout tool groups remain grouped.
- A separate saved layout for every mode, including Object, Edit, Sculpt, and
  Paint modes.
- Restore the current mode or every mode to Blender's defaults.

## Install

1. In Blender, open **Edit > Preferences > Get Extensions**.
2. Open the drop-down menu and choose **Install from Disk**.
3. Select `n_panel_manager-1.0.0.zip` from the `dist` folder.
4. Enable the extension if Blender does not enable it automatically.
5. In a 3D View, press `T` if the Toolbar is hidden, then click the gear icon
   at its top.

The dialog edits the layout for the 3D View's current mode. Switch modes and
open it again to customize that mode.
